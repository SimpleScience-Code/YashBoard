## ⌨️ About the Project

So my project is a custom-made, fully functional keyboard. It also has a built-in macro key. It is made from scratch, with hot-swap sockets and custom-made keycaps, you know, because I want to feel comfy while typing, don't I?
This keyboard is supposed to be mainly used by gamers and video editors, having an OLED screen and swappable module
